                    말투에 오신 걸 환영합니다

                    랑프두잇의 과장이 되어, 까다로운 상사·부하 직원과 음성으로 대화하며 말투·톤·표정을 연습합니다.

                    1. 🎙 마이크·📷 카메라 권한 대화 중 목소리와 표정을 분석합니다. 브라우저가 물으면 "허용"을 눌러주세요. 카메라는 없어도 됩니다.
                    2. 🎧 이어폰 권장 스피커 소리가 마이크로 들어가면 3초 대답 감지가 틀어질 수 있습니다.
                    3. 🔒 내 정보 영상은 서버로 보내지 않고 수치만 분석합니다. 녹음은 글자로 바꿀 때만 쓰고, 연습 기록은 내 PC(data.db)에만 저장됩니다.
                    4. 🤖 AI 고지 상대 인물의 얼굴 사진과 목소리는 AI로 생성되었습니다. 인물과 회사는 모두 가상이며, 연봉·채용 비용은 게임용 가상 수치입니다.
                    5. 💳 비용 내 OpenAI API 키로 동작합니다. 한 판에 보통 10~30원 정도이고, 오른쪽에서 실시간으로 확인하고 한도를 정할 수 있습니다.

                    이 분석은 연습용 참고 자료이며 심리 진단이 아닙니다.
