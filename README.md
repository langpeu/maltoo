# 말투 (maltoo)

> 직장 갈등 상황에서 **나의 말투·목소리 톤·표정**을 분석하고 교정해 주는 롤플레이 연습 웹서비스

말투가 공격적이거나 억양 때문에 오해를 사는 사람이, 현실에 있을 법한 "문제 있는" 상사·부하 직원과 음성으로 대화하며 연습합니다.
답변할 때마다 **대사 + 목소리 톤 + 얼굴·눈 표정**을 함께 분석해서, 상대의 감정 변화와 목표 달성도를 실시간으로 보여주고 교정 방법을 안내합니다.

---

## 핵심 기능

### 1. 직장 갈등 시나리오 (7종)

### 2. 실제 같은 압박: 생각할 시간 없음
1. 상대 대사를 **TTS로 재생** → 끝나는 즉시 마이크 자동 ON, **3초 카운트다운**
2. 3초 안에 말을 시작하면 녹음 계속, **1.5초 무음**이면 답변 종료
3. 3초 안에 말이 없으면 상대가 **공격적으로 재촉** (최대 2회, 점점 강해짐)
4. 끝까지 무응답이면 "응답 회피"로 기록
5. 대화는 상대가 감정 상태에 맞춰 받아치며 **최대 5턴**

### 3. 멀티모달 분석 (매 턴)
모든 수치는 **사용자의 평소 상태(첫 사용 시 30초 기준 측정)** 와 비교합니다.

**목소리 톤** (브라우저 Web Audio로 측정)
| 항목 | 해석 |
|---|---|
| 음량 · 급상승 구간 | 언성 높임, 흥분 |
| 음높이 변화 폭 | 너무 단조로우면 차갑게/무관심, 급상승은 격앙 |
| 말 속도 | 빨라지면 방어적·다급 |
| 문장 끝 억양 | 뚝 떨어지면 단정·명령조, 살짝 올라가면 부드러움 |
| 단어 강세 | 비꼼·압박 ("**제가** 언제요?") |
| 반응 시간 · 말 끊김 | 당황, 회피 |
| 짧은 한숨 · 혀 차는 소리 | 짜증 (근사 감지) |

**얼굴·눈 표정** (MediaPipe Face Landmarker, 브라우저 로컬 처리)
- 시선 회피, 눈 굴리기, 미간 찌푸림, 한쪽 입꼬리(비웃음), 입술 다묾, 고개 젖힘, 눈 깜빡임, 무표정 지속
- **듣는 중 / 3초 침묵 중 / 말하는 중** 세 구간으로 나눠 측정
- **영상은 서버로 전송하지 않음** — 수치 요약만 분석에 사용

**대사** — 음성 인식 결과 문장을 gpt-4o-mini가 톤·표정 수치와 함께 분석

### 4. 화면 구성
```
┌───────────────────────────────┬──────────────────┐
│                               │ 상대 감정 게이지   │
│   상대 인물 이미지 + 대사        │ 목표 달성도        │
│   (내 카메라는 구석에 작게)       │ 내 톤 미터         │
│                               │ API 비용 (작게)    │
├───────────────────────────────┴──────────────────┤
│ ▁▂▅▇▅▂▁▂▃▆█▆▃▁  파형 + 음높이 선 (실시간)             │
│    😠      🔊        ⤵        👀   감정 체크포인트      │
│ "그건 제가 언제 그랬다는 거죠"   인식된 문장             │
└──────────────────────────────────────────────────┘
```

- **오른쪽 패널 (실시간)**
  - 상대 감정: 분노 / 신뢰 / 방어심 수치와 변화량, 변화 이유 한 줄
  - 목표 달성도: 진행률 % + 세부 체크리스트
  - 내 톤 미터: 차분 ↔ 격앙, 따뜻 ↔ 차가움
  - 비용: 이번 연습 / 오늘 / 이번 달
- **하단 분석 띠**
  - 파형 + 음높이 선, 평소보다 높은 구간 강조, 상대 발화 구간은 회색
  - 감정 체크포인트 2단계
    - 즉시(브라우저 측정): 🔊 언성 상승, ⤵ 끝 억양 하강, ⏩ 말 빨라짐, 😮‍💨 한숨, 😠 찌푸림, 👀 시선 회피, 😏 비웃음
    - 턴 종료 1~2초 후(gpt-4o-mini): 💢 공격적 표현, 🛡 변명조, ✅ 잘한 표현
  - 핀 클릭 시 설명 + 해당 구간 다시 듣기, 턴별 탭
- **상대 인물 이미지**: 감정 게이지에 따라 표정 5단계 자동 전환
  - 😐 평온 → 😒 짜증 → 😠 분노 → 🤬 폭발 → 😌 누그러짐

### 5. 결말 · 교정
- 결말: 🟢 성공 / 🟡 부분 성공 / 🔴 실패
- 문제 표현 하이라이트 → 부드러운 대안 문장
- 억양 팁을 수치로 제시 ("문장 끝을 살짝 올리세요", "속도를 20% 줄이세요")
- **모범 답변 듣기**: 교정 문장을 좋은 억양의 TTS로 재생
- **다시 말해보기**: 재녹음 후 이전 점수와 비교
- 회차별 기록 및 개선 추이 그래프

### 6. 결말 장치: 연봉 감액 · 퇴사

**상사 시나리오 (1, 2, 3, 6) — 실시간 연봉 감액**
- 오른쪽 패널 맨 위에 **내 연봉** 표시 (과장 기본 4,700만 원, 설정에서 변경)
- 잘못 보이면 즉시 감액 + 인사고과 메모 ("−120만 원 · 태도 문제 기록됨")

| 원인 | 변동 |
|---|---|
| 상사 분노 +10 | −30만 원 |
| 상사 신뢰 −10 | −20만 원 |
| 💢 공격적 표현 / 🔊 언성 상승 | −40만 원 |
| 응답 회피 (재촉까지 무응답) | −50만 원 |
| ✅ 잘한 대응 | +20만 원 (깎인 금액의 **절반까지만** 회복) |

- 결말 인사고과: 🟢 A (+3%) / 🟡 C (동결) / 🔴 D (−5%) / 💀 "인사팀 면담 요청"
- 금액은 `config.json`에서 조정

**부하 직원 시나리오 (4, 5, 7) — 퇴사 위험도**
- 오른쪽 패널에 **퇴사 위험도 0~100%** 게이지
- 단계별 상태 메시지: 30% "표정이 굳었습니다" → 60% "점심시간에 이직 사이트를 보고 있습니다" → 90% "책상 정리를 시작했습니다"
- 100% → **퇴사 엔딩**: 사직서 장면 + 손실 표시 ("대체 인력 채용 약 1,500만 원, 업무 공백 3개월")
- 너무 물러도 손해: 7번은 **팀 불만** 게이지를 함께 두어, 문제를 덮으면 다른 팀원이 이탈하는 엔딩

> 연봉·채용 비용은 게임용 **가상 수치**입니다.

### 7. 회사 세계관 · 소문 · 누적 기억

무대는 가상의 로봇 제조 회사 **랑프두잇(LangpeuDoit)** 입니다. 인물들은 같은 회사에서 서로 소통합니다.

```
            최 상무 (본부장)
                 │
             김 부장
           ┌─────┴─────┐
        박 팀장      한 팀장
           │           │
        ★ 나 (과장)  ───┘
     ┌─────┼─────┐
  이 사원  정 주임  윤 대리
```

**인물 간 관계** (`scenarios/world.json`)
| 인물 | 다른 인물에 대한 생각 |
|---|---|
| 이 사원 | 박 팀장의 무리한 일정에 불만 |
| 정 주임 | 김 부장의 공 가로채기를 경멸 |
| 윤 대리 | 한 팀장을 무서워함 (육아 조퇴 눈치) |
| 박 팀장 ↔ 한 팀장 | 승진 경쟁 라이벌 |
| 최 상무 | 김 부장을 편애 |

- 대화 중 다른 인물을 언급하면 관계에 맞춰 반응합니다.
  - 부하 직원과 **상사를 같이 욕하면 호감도 상승**, 퇴사 위험도 하락
  - 김 부장 앞에서 최 상무를 깎아내리면 신뢰 하락, 연봉 감액

**소문 시스템**
- 험담은 일정 확률로 **소문이 되어 퍼집니다.**
  - 다음 해당 상사 시나리오의 첫마디가 바뀜 ("이 사원한테 내 얘기 했다며?") + 시작 연봉 감액
  - 상사에게 부하를 험담하면 상사 신뢰는 오르지만 해당 부하에게 소문이 감
- 소문 버전 첫마디는 인물별 2~3개를 미리 정해 캐시 (추가 비용 거의 없음)
- 최종 리포트에서 "험담은 즉효지만 위험이 큰 전략"으로 피드백

**누적 기억**
- 인물별 나에 대한 **호감도·신뢰**, 퍼진 **소문 목록**, 현재 연봉을 `data.db`에 누적 저장
- 시나리오를 다시 하거나 다른 시나리오를 해도 이전 행동이 반영됨
- 설정의 **"새 회사 입사"** 버튼으로 초기화

### 8. 비용 관리
- 오른쪽 패널에 **이 앱이 사용한 OpenAI API 비용**을 실시간 표시 (원화/달러, 기능별)
- 응답의 실제 사용량(토큰·음성 길이) × `config.json` 가격표로 계산한 **추정치**
- **일일/월 한도** (기본 $0.50 / $5) — 80% 경고, 100% 도달 시 **서버에서 API 호출 차단**
- 캐시 재생은 "재사용 · $0"으로 표시
- 비용 기록은 로컬 `data.db`에 API 키 끝 4자리별로 집계
- OpenAI 대시보드의 프로젝트 예산 설정을 이중 안전장치로 권장

> 대체 모델(`gpt-realtime-2.1-mini`, `gpt-transcribe` 등)로 **`config.json`의 모델 이름만 바꾸면** 됩니다.

## API 키

- `.env` 파일이 필요 없습니다. 처음 접속하면 **OpenAI API 키 입력 창**이 뜹니다.
- 키는 **브라우저 localStorage에만 저장**되고, 요청 시 로컬 서버로 전달되어 해당 요청에만 사용됩니다. 서버는 키를 파일·DB에 저장하지 않습니다.
- 입력 즉시 무료 확인 요청으로 유효성을 검사하며, 설정에서 `sk-...abcd` 형태로 확인·변경·삭제할 수 있습니다.

## 캐시 자산 (GitHub에 포함)

자주 쓰는 음성·이미지는 **한 번만 생성하고 저장소에 함께 커밋**해서, 내려받은 사람도 생성 비용 없이 재사용합니다.

| 경로 | 내용 | 수량 |
|---|---|---|
| `assets/audio/` | 시나리오 첫마디 + 1·2차 재촉 대사 + 소문 버전 첫마디 mp3 | 약 35~40개 |
| `assets/characters/<인물>/<표정>.png` | 인물 7명 × 표정 5단계 | 35장 |
| `assets/endings/` | 사직서 장면(부하 3명), 인사고과 통보 장면 | 4장 |
| `assets/**/manifest.json` | 생성 모델, 일시, 프롬프트 기록 | |

- 파일 키는 **대사 문장 + 목소리 + 말투 지시**(이미지는 인물 + 표정 + 프롬프트)로 정합니다. **모델 이름은 키에 넣지 않으므로** 모델을 바꿔도 캐시가 유지됩니다.
- 대사나 프롬프트를 고치면 해당 파일만 재생성되고, 설정 화면에서 "강제 재생성"도 가능합니다.
- 설정 → **상대 고정 음성 미리 만들기**로 21개를 한 번에 생성할 수 있습니다. 생성된 `assets/audio/` 파일을 커밋하면 다른 사람도 재사용합니다.
- 이미지는 기본 초상을 먼저 생성한 뒤 그 이미지를 기준으로 표정만 편집해서 같은 얼굴을 유지합니다.

## 실행

```bash
pip install -r requirements.txt
python main.py
# 브라우저가 자동으로 http://127.0.0.1:8000 을 엽니다 (Chrome / Edge 권장)

# 테스트
pytest
```

- 마이크·카메라 권한이 필요합니다 (`localhost`에서 동작).
- **이어폰 사용 권장**: 스피커 소리가 마이크로 들어가면 3초 무음 감지가 틀어질 수 있습니다.

## 고지

- 상대 인물의 **음성과 이미지는 AI로 생성**되었습니다.
- 시나리오의 인물은 모두 가상이며 실존 인물과 관계없습니다.
- 이 서비스의 분석은 연습용 참고 자료이며 심리 진단이 아닙니다.
